# Техническое задание — CarService1 (AutoDuck)

## 1. Назначение

Кроссплатформенное приложение для компании **AutoDuck**, предоставляющее услуги:

- Запись на ремонт автомобиля
- Запись на мойку автомобиля
- Аренда автомобилей с онлайн-оплатой и депозитом

Целевые платформы: **Web**, **Android**, **iOS** — единый кодовая база.

## 2. Технологический стек

| Слой | Технология |
|------|-----------|
| Фреймворк | React Native + Expo SDK 51 |
| Роутинг | Expo Router v3 (file-based) |
| Язык | TypeScript |
| Бэкенд / БД | Supabase (Postgres + Auth + Storage + Realtime) |
| Платежи | Stripe (Payment Sheet, Apple Pay, Google Pay) |
| Аутентификация | Supabase Auth: OAuth Google + Apple |
| Состояние | Zustand + React Query |
| i18n | i18next + expo-localization |
| Push | expo-notifications |
| Карты | не входит в MVP |
| UI | Кастомные компоненты на base RN + react-native-reanimated |

## 3. Роли пользователей

### 3.1 Клиент
- Регистрация/вход (OAuth Google/Apple)
- Просмотр услуг и автомобилей
- Запись на ремонт/мойку
- Аренда авто
- Оплата (Stripe)
- История заказов
- Оставить отзыв
- Push-уведомления

### 3.2 Администратор / менеджер AutoDuck
- Дашборд с записями
- Управление автопарком
- Управление услугами и ценами
- Просмотр платежей
- Управление статусами заказов

## 4. Функциональные требования

### 4.1 Услуги ремонта (Repair)
- Каталог услуг с категориями (двигатель, тормоза, подвеска и т.д.)
- Описание, цена (от), длительность
- Бронирование на дату/время
- Указание авто клиента (марка/модель/VIN опц.)
- Оплата при бронировании или по факту

### 4.2 Мойка (Wash)
- Пакеты услуг (Basic / Premium / Deluxe)
- Запись на ближайшие свободные слоты
- Оплата при бронировании

### 4.3 Аренда (Rental)
- Каталог авто (фото, характеристики, цена/сутки)
- Выбор периода аренды
- Предавторизация депозита через Stripe
- Возможность сохранить карту
- Apple Pay / Google Pay

### 4.4 Профиль и история
- Личные данные
- Список авто пользователя
- История записей и платежей
- Управление способами оплаты
- Отзывы пользователя

### 4.5 Отзывы и рейтинги
- 5-балльная шкала
- Текстовый отзыв
- Привязка к конкретному заказу
- Средний рейтинг услуг

### 4.6 Push-уведомления
- Подтверждение записи
- Напоминание за 24 часа и за 1 час
- Изменение статуса заказа
- Готовность авто

### 4.7 Мультиязычность
- Английский (en) — по умолчанию
- Русский (ru)
- Португальский Бразилия (pt-BR) — основной для бренда

## 6. Структура БД (Supabase)

Подробная схема в `supabase/schema.sql`. Основные таблицы:

- `profiles` — расширение `auth.users`
- `vehicles` — авто клиентов
- `service_categories` — категории услуг
- `services` — каталог услуг (ремонт, мойка)
- `rental_cars` — автопарк для аренды
- `bookings` — записи на услуги
- `rentals` — договоры аренды
- `payments` — платежи (Stripe)
- `reviews` — отзывы
- `notifications` — лог push

Используется Row Level Security (RLS) на всех таблицах.

## 8. Mock-данные

Для MVP используются mock-данные в `lib/mock-data.ts`. Подключение к реальному Supabase активируется при заполнении `.env`:

```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_ANON_KEY=...
EXPO_PUBLIC_STRIPE_PUBLISHABLE_KEY=...
```
